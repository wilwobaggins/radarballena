# RadarBallena / DeepSignal Engine

RadarBallena es un sistema de inteligencia para mercados de predicción. Su objetivo es obtener mercados activos, filtrarlos, enriquecerlos con contexto, analizarlos con DeepSignal Engine, guardar los resultados y mostrarlos en un dashboard.

El flujo objetivo del MVP es:

```txt
Mercado
↓
Contexto
↓
DeepSignal Analysis
↓
Base de datos
↓
Dashboard
